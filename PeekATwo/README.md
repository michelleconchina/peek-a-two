# Peek A Two

Peek A Two is a SwiftUI memory card matching game built with the MVVM architecture pattern.

Players flip cards, find matching pairs, and earn points through a clean and responsive game interface while exploring core SwiftUI concepts through hands-on development.

## Features

- SwiftUI-based UI
- MVVM architecture
- Animated card flipping
- Responsive grid layout
- Score tracking
- New Game reset functionality

## Learning Goals

This project is also a SwiftUI learning journey focused on:

- State management with `@StateObject` and `@Published`
- Building reusable SwiftUI views
- MVVM architecture patterns
- Animations and transitions
- Grid layouts with `LazyVGrid`
- Game state and logic handling
- Navigation and app structure
- SwiftUI performance and responsiveness
